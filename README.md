# OrangeHRM-Manual-QA-Project
Manual QA testing project for the OrangeHRM web application, covering the Software Testing Life Cycle (STLC) from requirements analysis to test execution and defect reporting.

## Scope of Testing
Testing focuses on the following functionalities:
- **Login and Logout**
- **Employee Management (PIM)**

This project covers selected functionalities only and does not represent complete testing of the OrangeHRM application.

## Testing Activities
- Requirements Documentation and Analysis
- Test Scenario Design
- Test Case Design
- Manual Test Execution
- Defect Reporting

## Tools Used
- **GitHub** — Project documentation
- **Jira** — Defect tracking
- **Google Sheets / CSV** — Test case documentation

## Test Results
A total of **27 test cases** were executed.

- **Passed:** 26
- **Failed:** 1
- **Pass Rate:** 96.30%

One issue related to Dashboard visibility after logout was documented in the bug report and tracked in Jira.

For detailed results, refer to the Test Execution Report and Bug Reports.
