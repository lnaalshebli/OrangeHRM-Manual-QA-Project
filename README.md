# OrangeHRM-Manual-QA-Project
Manual QA testing project for the OrangeHRM web application, covering the Software Testing Life Cycle (STLC) from requirements analysis to test execution and defect reporting.

Scope of Testing

Testing was limited to selected functionalities:

Login and Logout

Employee Management (PIM)

The project covers selected test scenarios related to login validation, logout behavior, and basic employee management operations, including adding, viewing, editing, and searching for employees.

Note: This project covers selected functionalities only and does not represent complete testing of the OrangeHRM application.

Testing Activities

Requirements documentation and analysis

Test scenario and test case design

Manual test execution

Defect reporting

Tools Used

GitHub — Project documentation

Jira — Defect tracking

Google Sheets and CSV — Test case documentation

Test Results

A total of 27 test cases were recorded in the execution report.

Passed: 26

Failed: 1

Pass Rate: 96.30%

One issue related to Dashboard visibility after logout was documented in the bug report and tracked in Jira.

For detailed execution results and defect information, refer to the relevant project files.
